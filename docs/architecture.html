Процессный синглтон

Оба движка — процессные синглтоны. GoBackend хранит туннель в памяти и сравнивает объекты Tunnel по ссылке. После пересоздания Activity новый экземпляр не смог бы распознать активный туннель.

Как добавить новый протокол

  1. Создать класс, реализующий ProtocolEngine.
  2. Добавить строку в ProtocolEngineFactory.forProtocol():
"trojan" -> TrojanEngine.get(context)

Dart-слой не требует изменений.

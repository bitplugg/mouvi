🚀 Быстрый старт

  1. Скачайте APK из GitHub Releases
  2. Установите APK на Android-устройство
  3. Разрешите VPN-права в настройках системы
  4. Импортируйте конфигурацию (.ovpn, Shadowsocks JSON, VLESS)
  5. Подключитесь

🏗 Архитектура

Муви использует нативный Android VPN-движок с интерфейсом ProtocolEngine, что позволяет добавлять новые протоколы без изменения Dart-слоя:

  • WireGuardEngine — через com.wireguard.android.backend.GoBackend
  • AmneziaWgEngine — через org.amnezia.awg.backend.GoBackend
  • ProtocolEngineFactory — выбор движка по имени протокола

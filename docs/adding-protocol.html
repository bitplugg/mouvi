📖 Как добавить новый VPN-протокол

Добавление нового протокола в Mouvi занимает три шага.

1 Создать класс движка
Создать файл android/app/src/main/kotlin/com/bitplugg/vpn_client/VlessEngine.kt: 
package com.bitplugg.vpn_client

class VlessEngine private constructor(context: Context) : ProtocolEngine {
    // Реализовать connect, disconnect, getState, setStateListener
    
    companion object {
        @Volatile private var instance: VlessEngine? = null
        fun get(context: Context): VlessEngine {
            return instance ?: synchronized(this) {
                instance ?: VlessEngine(context).also { instance = it }
            }
        }
    }
}
2 Зарегистрировать в фабрике
В ProtocolEngineFactory.kt добавить строку: 
fun forProtocol(protocol: String, context: Context): ProtocolEngine? = when (protocol) {
    "wireguard" -> WireGuardEngine.get(context)
    "amneziawg" -> AmneziaWgEngine.get(context)
    "trojan" -> TrojanEngine.get(context) // ← новая строка
    else -> null
}
3 Включить протокол в Dart-слое
Добавьте его в VpnProtocolType.engineSupported в lib/core/models/vpn_config.dart, проверьте подпись, импорт конфигурации и тесты. Контракт MethodChannel не меняется.
4 Проверить сборку
dart format lib test, flutter analyze, flutter test и flutter build apk --debug
